# Jetti Resources

> Jetti Resources is a Boulder, Colorado based metallurgical technology company whose catalytic
> leaching process unlocks copper from low-grade primary sulfide ores such as chalcopyrite —
> roughly 70% of the world's copper resources — that conventional pyrometallurgy cannot treat
> economically and that bioleaching cannot treat at all because of the passivation layer that
> halts extraction. Jetti's catalyst prevents that layer from forming, enabling uninterrupted
> heap and stockpile leaching through existing bioleach and SX-EW circuits using modular,
> standardized micro plants. Jetti licenses a chemical and process technology to mine operators;
> it is not a software vendor. This file was generated by API Evangelist from publicly reachable
> pages; it is not published by the company.

## Developer surface

There is none. As of 2026-08-23 the following were probed on www.jettiresources.com and all
returned HTTP 404: /llms.txt, /openapi.json, /openapi.yaml, /swagger.json, /v1/openapi.json,
/api-docs, /api, /docs, /redoc, /graphql, /.well-known/security.txt,
/.well-known/openid-configuration, /.well-known/oauth-authorization-server,
/.well-known/api-catalog, /.well-known/ai-plugin.json, /.well-known/agent-card.json and
/.well-known/agent.json. A deliberately invalid control path also returned 404, so these are
genuine misses rather than a single-page-app catch-all. The apex jettiresources.com 301-redirects
to the www host. No OpenAPI, AsyncAPI, GraphQL SDL, WSDL, Protobuf, MCP server, A2A agent card,
SDK, CLI or package-registry client library was found on any host, in any public registry
(npm, PyPI), or on GitHub. robots.txt allows everything except /api/, which is the site's own
Next.js route handlers behind the website chat assistant and the Rosetta widget — an internal
application surface, not a published developer API; it was not probed, because robots disallows it.
A GitHub organization at https://github.com/Jetti-Resources exists (created 2026-01-12) but
publishes zero repositories and carries no website, email or location field, so first-party
ownership cannot be established and it is not wired as a pointer.
